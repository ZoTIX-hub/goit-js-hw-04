# Домашнє завдання 4 – Об’єкти

## Опис
Четверте домашнє завдання з JavaScript.  
Практика роботи з об’єктами, методами об’єктів, ключовим словом `this`, ітерацією по об’єктах та обчисленнями.

## Технології / стек
- JavaScript (ES6+)
- Об’єкти та методи об’єктів
- Ключове слово `this`
- Цикл `for...in` (або `Object.values()`)
- Методи масивів (`reduce` або простий цикл для підрахунку)
- Шаблонні рядки0

## Функціонал

| Файл       | Функція / об’єкт                     | Що робить                                                                 |
|------------|--------------------------------------|---------------------------------------------------------------------------|
| task-1.js  | `isEnoughCapacity(products, containerSize)` | Перевіряє, чи помістяться всі товари (сума значень об’єкта) у контейнер   |
| task-2.js  | `calcAverageCalories(days)`          | Обчислює середньодобове споживання калорій за тиждень (7 днів)            |
| task-3.js  | об’єкт `profile` з методами          | Зміна імені (`changeUsername`), додавання годин (`updatePlayTime`), отримання інформації (`getInfo`) |

## Приклади роботи (виведення в консоль)

Всі тестові виклики вже присутні в кінці кожного файлу та залишені для перевірки ментором.

Приклади результатів:

- `isEnoughCapacity({ apples: 2, grapes: 3, carrots: 1 }, 8)` → `true`
- `isEnoughCapacity({ apples: 4, grapes: 6, lime: 16 }, 12)` → `false`
- `calcAverageCalories([...7 об’єктів з калоріями...])` → `3180`
- `calcAverageCalories([])` → `0`
- `profile.getInfo()` після змін → `"Marco has 320 active hours!"`
